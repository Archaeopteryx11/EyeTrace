# Datos de la evaluación

Esta carpeta se llena automáticamente al usar el **modo evaluación** de EyeTrace (tecla **E** en la pantalla de inicio).

| Archivo | Contenido |
|---|---|
| `sesiones.csv` | Una fila por participante con el resumen de su sesión |
| `exactitud.csv` | Una fila por punto de la prueba de exactitud |
| `practica.csv` | Una fila por figura practicada |
| `encuesta.csv` | Respuestas de la encuesta |
| `fotogramas/` | Un CSV por sesión con cada fotograma de la cámara (no se sube a GitHub por su tamaño) |
| `obras/` | La obra del minuto de dibujo libre de cada participante |
